# Статиите от блога във Facebook

Сайтът пуска статиите в страницата на Creatium Lab сам: новите веднага щом излязат, по-старите по една на ден между 09:00 и 20:00. В админа (**Сайт → Блог**) колоната **Facebook** показва кои са пуснати, а бутонът **Пусни сега** пуска статия веднага, извън реда.

Нужно е веднъж да се свърже страницата. Отнема около 15 минути, по-лесно е от компютър. Менютата на Meta се сменят често, затова имената по-долу може леко да се различават.

## 1. Приложение в Meta (безплатно)

1. Отворете https://developers.facebook.com и влезте с акаунта, който е администратор на страницата.
2. **My Apps → Create app**. Име: например „Creatium Lab блог“.
3. Ако пита за случай на употреба, изберете управление на страница („Manage everything on your Page“). Ако пита за вид, изберете **Business**.
4. **App settings → Basic**: тук са **App ID** и **App Secret** (бутон „Show“). Не ги пращайте в чат или имейл; въвеждат се само на сървъра в стъпка 3.
5. В същата страница попълнете **Privacy Policy URL**: `https://creatiumlab.com/poveritelnost`.

## 2. Ключ за достъп

1. Отворете **Tools → Graph API Explorer** (https://developers.facebook.com/tools/explorer).
2. Горе вдясно изберете вашето приложение.
3. Добавете разрешенията `pages_show_list`, `pages_read_engagement` и `pages_manage_posts`.
4. Натиснете **Generate Access Token**, потвърдете и изберете страницата Creatium Lab.
5. Копирайте ключа (дългият текст в полето **Access Token**).

Ключът от Explorer изтича след около час, затова направете стъпка 3 веднага.

## 3. Свързване на сървъра

В терминала на Webdock:

```bash
sudo -iu deploy
cd /var/www/creatiumlab && php artisan creatium:facebook-connect
```

Командата пита за App ID, App Secret и ключа от стъпка 2 (последните два не се виждат, докато ги поставяте). Тя ги разменя за постоянен ключ на страницата и го записва в `.env`. App Secret не се записва никъде.

Проба с една статия веднага:

```bash
php artisan creatium:facebook-publish
```

## Ако нещо не работи

- **Постът се вижда само от вас:** приложението е в режим „Development“. В горната част на таблото на приложението превключете на **Live** (иска Privacy Policy URL от стъпка 1.5).
- **В админа пише „Публикуването във Facebook е спряно“:** ключът вече не важи (например след смяна на паролата във Facebook). Повторете стъпки 2 и 3.
- **Статия с „Грешка“:** задръжте мишката върху нея, за да видите причината, и натиснете **Опитай пак**.
